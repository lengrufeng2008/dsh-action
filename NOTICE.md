# Notice

`dsh-action` is a DeepSeek Harness GitHub Action for pull-request review.

It is inspired by the CI-native review workflow of
[anthropics/claude-code-action](https://github.com/anthropics/claude-code-action); no source code is
copied. The implementation installs DSH, installs this bundle into the headless profile, and uses the
`pr-review` skill.

The action is not affiliated with Anthropic, GitHub, or DeepSeek.
